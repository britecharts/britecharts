Ship an agent skill for coding assistants in `skills/britecharts`. It gives an agent each chart's exact data shape, accessors and events, where each chart's tooltip attaches, how to use React and the wrappers, and the v2 code that no longer works in v3. Install it with `npx skills add britecharts/britecharts`, or copy it from `node_modules/@britecharts/core/skills/britecharts` into your agent's skills folder.
