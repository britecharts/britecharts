Scatter Plot

Reusable Scatter Plot API class that renders a simple and configurable scatter chart.

Example

import { select } from 'd3-selection';
import { scatterPlot } from '@britecharts/core';

// dataset: [{ name, x, y }]
const scatterPlotChart = scatterPlot();

scatterPlotChart
    .grid('horizontal')
    .width(500);

select('.css-selector')
    .datum(dataset)
    .call(scatterPlotChart);

This function creates the graph using the selection as container

Gets or Sets whether a keyboard can move through the chart's data points: the chart takes one tab stop, the arrow keys move between points, Home and End go to the first and last, and Escape lets go. The tooltip and highlights follow focus as they follow the pointer. On by default.

tooltip(_x) ⇒ module | null​

Gets or Sets the tooltip the chart shows: a tooltip() or a miniTooltip(), set on this chart only. The chart connects it to its pointer and keyboard events, draws it in place, and sets the labels its data points need, unless they were set on the tooltip; it does so now if the chart has drawn, and again on every draw. Its event handlers go under the britechartsTooltip namespace. Null, or another tooltip, removes the one it had.

Kind: method of scatterPlot
Returns: module | null - Current tooltip or Chart module to chain calls
Throws:

  • Error When the tooltip is already set on another chart

Access: public

ParamTypeDescription
_xmodule | nullThe tooltip to show

Example

scatterPlot().tooltip(miniTooltip()).render('#chart', data);

render(target, [data]) ⇒ module​

Draws the chart into a target: a CSS selector, an element or a d3 selection, as select(target).datum(data).call(chart) does. A selector draws into the first element it matches. Without data, the chart redraws with the data it last drew there.

Kind: method of scatterPlot
Returns: module - The chart module, to chain calls
Throws:

  • Error When the target matches no element

Access: public

ParamTypeDescription
targetString | Element | D3SelectionWhere to draw the chart
[data]ObjectThe data to draw

Example

scatterPlot().width(600).render('#chart', data);
