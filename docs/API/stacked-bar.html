Stacked Bar

Stacked Area Chart reusable API module that allows us rendering a multi area and configurable chart.

Requires: module:d3-array,
Example

let stackedBar = stackedBar();

stackedBar
    .width(containerWidth);

d3Selection.select('.css-selector')
    .datum(dataset.data)
    .call(stackedBar);
