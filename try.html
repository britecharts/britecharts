Try Britecharts

Open a running example on StackBlitz, with nothing to install. Each draws a bar chart and a line chart with their tooltips, switches to dark mode, and moves through the data with the keyboard. StackBlitz installs the packages from npm and starts the app in a new tab, which takes about half a minute.

Plain JavaScript

Britecharts in plain JavaScript: a bar chart and a line chart with tooltips, dark mode and keyboard navigation

React

Britecharts in React: a bar chart and a line chart with tooltips, dark mode and keyboard navigation

The examples live in the repository's examples folder. To run one on your machine, copy its folder, then run npm install and npm run dev.
