# vanilla consumer

A plain-JavaScript project that depends on `@britecharts/core` from the packed
tarball (`file:../../.tarballs/core.tgz`), exactly as a user would depend on it
from npm. One HTML page per consumption path:

| Page | Path exercised |
|---|---|
| `cdn-bundle.html` | `dist/cdn/bundle/core.cdn.min.js` as a script tag, global `core` |
| `cdn-chart.html` | `dist/cdn/charts/bar.cdn.min.js` as a script tag, global `core.bar` |
| `umd-bundle.html` | `dist/umd/bundle/core.bundled.min.js` (the package `main`) through Vite |
| `umd-chart.html` | `dist/umd/charts/bar.min.js` through Vite |
| `esm-bundle.html` | `import { bar } from '@britecharts/core'` (the package `module` entry) |
| `esm-chart.html` | `import bar from '@britecharts/core/src/charts/bar/bar.js'` |
| `cdn-jsdelivr.html` | the published bundle from jsDelivr; only run by `smoke-published.yml` against a released version |

Stylesheets are covered across the pages: the CSS bundle via a `<link>` and via
a JS import, and the per-chart `common` + `bar` files both ways too.

`public/vendor/` is generated by `scripts/install-consumers.js` from the
installed package (CDN files, styles, a UMD `d3-selection`) so the script-tag
pages need no network. `node_modules/`, `dist/` and `public/vendor/` are
gitignored.
