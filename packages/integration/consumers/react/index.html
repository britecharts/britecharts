Britecharts React consumer

One page per way of loading @britecharts/react, on React 19. The Playwright suite in tests/browser.spec.js visits each one.

Every page but R5 is served from a production build; R5 is built in development mode, where StrictMode double-invokes effects.

  • R1–R2 · named imports from the package
  • R3 · per-component CommonJS build
  • R4 · per-component UMD build
  • R5 · development build under StrictMode (port 4175)
  • R6 · create, destroy, create by hand
